GitHub 上传步骤（无需命令行）

目前仅准备了本地源码与文档，尚未创建或上传远程仓库。

1. 从 TapeCode 项目文件界面下载/导出项目文件。如果下载得到 ZIP，请先在电脑解压，不要只上传 ZIP。
2. 登录你自己的 https://github.com/ ，点击右上角 + → New repository。
3. 仓库名建议 topeout-world；选择 Public，便于评委查看。简介可填：An original voxel creation sandbox built around the TapeOut ecosystem.
4. 因为项目已有 README，不必勾选自动生成 README。许可证暂不代选，确认源码授权方式后再添加。
5. 创建后点击 uploading an existing file；已有仓库则点击 Add file → Upload files。
6. 上传解压后的项目文件：index.html、logo.svg、submission-kit.html、release-plan.txt、README.md、GITHUB-UPLOAD.txt。确保 index.html 与 logo.svg 等位于同一级目录。
7. 提交说明可填：Initial public source snapshot and submission documentation。点击 Commit changes。
8. 用未登录窗口检查仓库可访问，点击 index.html 和 README.md 确认内容存在。报名表 GitHub 字段填浏览器显示的真实仓库主页地址，不是单个文件、ZIP 下载或 GitHub Pages 地址。
9. 将实际仓库链接发回，以便后续更新报名资料。本助手无法代你登录或推送，无需提供 GitHub 密码、令牌或验证码。

注意：
- 先检查并移除敏感信息，不能依赖上传后删除来撤回泄露。
- GitHub Pages 不能自动解析 tape://libs；不要将开启 Pages 当作游戏兼容问题已修复。
- 公开源码仍需决定许可证；未确认前不宣称 MIT 等授权。
- 以后修改代码可在同一仓库重新上传对应文件并提交清晰说明。不要删除仓库重建，也不要伪造开发历史。
- 本次上传不用修改或重新发布链上游戏，因此不需要为此支付链上 Gas。
