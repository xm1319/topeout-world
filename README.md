# TOPEOUT WORLD

An original voxel creation sandbox built around the TapeOut ecosystem.

灵感，在此诞生。世界，由你创造。

从 TapeCode.ai 创造中枢启程，在生态群岛中探索、建造和学习逻辑。

本项目为原型，尚未完成完整的桌面与手机验收。

## 玩法

- 不规则生态群岛、自由建造、采集与应用导航。

机关挑战目前是面板内本地模拟，不是链上电路执行，也尚未驱动三维世界机关。

## 运行

无 npm 和构建步骤，但三维游戏需要能解析以下共享库地址的环境：

```js
import * as THREE from 'tape://libs/three@0.186.1/three.module.js';
```

已收到运行反馈的路径：进入 https://tapecode.ai/ 的“浏览”，输入上述 X Layer 地址。登录要求及手机兼容性仍需测试。普通浏览器直接打开 index.html 不保证能加载该库。

不要禁用 CSP 或随意换用 CDN。公开网关兼容需要正确处理共享库解析、模块依赖与完整性校验。

## 链与数据边界

面向 BSC（56）和 X Layer（196），Base 与更多链按实际需求扩展，不限定一链一岛。主题岛位置不证明应用的真实部署归属。

网页上链不等于玩家存档或游戏计算上链。当前为本机单人游戏，无多人、云存档、支付或跨链存档同步；清除浏览器数据或更换入口可能丢失进度。

部署配置由应用注入 window.APP_CONFIG，不手工伪造配置，不将网络配置视为发布成功证明。

## 产品与商业方向

基础探索与建造免费。候选收入为可预览的新增装饰主题包、高级创作工具和明确标注商业合作的定制体验岛；价格、交付及退款规则尚未确定，当前不收费。

BNB / BEM 演示藏品仅是本地数据，不代表持仓或可提现资产，不承诺回本或分红。

## 开发优先级

1. 存档备份与恢复、桌面及手机体验验收。
2. 修复公共网关兼容，核验双链发布。
3. 三维互动机关与可导出、导入的关卡。
4. 真实玩家试玩与反馈修复。
5. 有明确需求后再开发收费与社区功能。

按验收条件推进，不承诺未经确认的日期。详细规划见游戏内白皮书及 release-plan.txt。
