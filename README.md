# TOPEOUT WORLD

An original voxel creation sandbox built around the TapeOut ecosystem.

原创体素创造沙盒：从一间工作室开始，在生态群岛中探索、建造和学习逻辑。

## Status / 当前状态

Prototype, not a fully tested production release.

- 用户报告的 X Layer 页面：`tape://7.2.260.tape/`。用户截图显示该版本在 TapeCode.ai 内置浏览器中成功呈现三维世界。
- 公共入口：https://7-2-260.tapekit.org/ 。已知问题：公共网关 CSP 拦截 `tape://libs` Three.js 模块，页面可显示但游戏无法启动。
- 上述运行情况来自用户截图；完整试玩、移动端验收及发布交易独立核验尚未完成。
- 本仓库工作版本包含发布后新增文件，不保证与该链上版本字节一致。发布前请固定提交版本并记录交易。
- BSC 同步发布为计划，当前没有本项目 BSC 发布验证记录。
- GitHub 存放源码，不自动提供可玩的游戏；启用 GitHub Pages 不会自动解决共享库兼容问题。

## Features / 现有代码功能

- 不规则生态群岛、自由建造与采集、导航与本机进度。
- 个人工作室、主题预览和成长章节。
- 本地 NAND / LATCH 教学与三关逻辑挑战。
- 作品 PNG 纪念卡、游戏内白皮书与路线图。
- 报名资料页和可下载的 24×24 PNG Logo。

这些功能需要实机验收。机关挑战是面板内本地模拟，不是链上电路执行，也尚未驱动三维世界机关。

## Run / 运行

主游戏是无构建步骤的 HTML/CSS/JavaScript 页面，但运行环境有要求：

```js
import * as THREE from 'tape://libs/three@0.186.1/three.module.js';
```

该共享库由 TapeCode 环境提供。普通浏览器直接打开文件或运行普通静态服务器，不保证能解析此地址。当前可参照用户验证路径：进入 https://tapecode.ai/ 的“浏览”，输入 `tape://7.2.260.tape/`。访客登录条件、手机兼容性须进一步验证。

`submission-kit.html` 不依赖 Three.js，可单独用浏览器打开以阅读文案和生成 Logo。

不要禁用浏览器 CSP，也不要把共享库替换为未经确认的 CDN 地址。需由 TapeCode / TapeKit 确认共享库解析、模块依赖与完整性校验的兼容方案。

## Architecture / 链与数据边界

目标网络为 BSC（56）与 X Layer（196）；Base 及更多链后续按需求扩展。生态主题岛位置不证明应用实际部署链。

网页发布到电路容器不等于游戏状态或逻辑在链上运行。当前为本机单人游戏，无多人、云存档、付费系统或跨链存档同步。清除浏览器数据或更换入口可能丢失本机进度。

部署配置由应用注入 `window.APP_CONFIG`；不手工伪造配置，不将网络配置作为发布成功证据。

## Business model / 商业方向

基础探索和建造免费。未来候选收入包括可预览的新增装饰主题包、高级创作工具和透明标注的定制体验岛服务；价格、支付、退款及交付规则尚未确定，当前没有收费。

BNB / BEM 演示藏品仅为本地数据，不代表持仓、收益或可提现资产。没有回本、分红或获奖承诺。

## Roadmap / 优先级

1. 存档备份与恢复，桌面/手机核心流程验收。
2. 解决公共网关依赖兼容并验证 X Layer 与 BSC 发布。
3. 三维互动机关和可导出/导入关卡。
4. 真实用户试玩、反馈、三分钟 Demo 及参赛证据。
5. 有明确需求后再验证收费与社区功能。

阶段按验收推进，不承诺未经确认的日期。详细内容见游戏内白皮书与 `release-plan.txt`。
