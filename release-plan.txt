TOPEOUT WORLD — 双链首发与商业计划
版本：双链准备版 / 机关室原型
状态更新：用户已提供 X Layer 地址 tape://7.2.260.tape/ 及其在 TapeCode 内置浏览器显示三维世界的截图。公共入口 https://7-2-260.tapekit.org/ 的 Three.js 共享库被 CSP 拦截，尚不能完整游玩。发布交易、当前源码与链上版本对应关系、BSC 发布和完整实机流程仍待核验；下文为计划与验收清单，不是已完成证明。

一、产品定位
面向喜欢体素建设、逻辑解谜的普通玩家，以及想以直观方式接触 TapeOut 的创作者。
核心主张：从一间工作室开始，创造自己的可互动岛屿。
当前新增：三关逻辑机关室，选择 AND/OR/XOR/NAND 模块，通过四组输入验证；本地记录通关。
当前边界：机关室是本地模拟，不是链上执行；不支持多人、公开作品托管、支付或资产跨链。

二、双链发布检查
1. 固定同一份 index.html 版本，分别选择 BSC（56 / BNB）和 X Layer（196 / OKB）的电路容器上传。
2. 发布须由用户在支持相应网络的发布界面授权；本助手没有发布交易工具。若界面不支持 X Layer，先用已确认的 X Layer 发布工具，不能声称已部署。
3. 每条链分别记录：处理器编号、电路编号、发布交易哈希、发布日期、实际可访问地址。
4. 通过 https://tapekit.org/ 输入实际地址。依据用户截图，BSC 示例格式为 #电路编号@处理器编号；X Layer 为 #电路编号@2.处理器编号。不要使用示例数值作为真实地址。
5. 验证游戏依赖的 tape://libs/three@0.186.1/three.module.js 在实际网关中可加载；未验证前不宣称 TapeKit 兼容完成。
6. 验证桌面和手机：进入游戏、群岛全景、登岛、建造/挖掘、工作室、三关机关、暂停恢复、刷新存档、作品图片下载。
7. 确认隐藏页面自动暂停、无钱包能游玩、错误输入不执行脚本。
8. 两条链上托管页面不等于存档上链，也不保证跨入口同步；不同网关或来源的本地存储可能不同。
9. 部署配置由应用注入 APP_CONFIG，不手工写入地址或伪造链配置。

三、商业方案（提案，未开启收费）
免费层：探索、基础建造、起始工作室、逻辑入门挑战。现有免费主题保持免费。
候选付费产品一：固定内容建筑/装饰主题包。展示完整预览、包含物品和使用范围，不卖随机抽奖或收益。
候选付费产品二：高级创作工具，例如批量编辑、模板管理、作品版本备份。先验证需求，再开发；当前未提供。
候选服务三：为生态项目提供透明标注的品牌体验岛和主题挑战设计。按交付范围报价，不伪装官方合作。
暂不推出订阅。只有稳定更新与持续服务形成后再测试，取消后不删除既有作品。
定价需要访谈和用户确认，本版不设售价、不接支付、不许诺收益。
成本项：内容与美术、工具开发、支持与审核、未来服务托管、支付手续费和退款。收入应覆盖真实成本，不依赖代币升值或新玩家补贴旧玩家。

四、留存与获客
首次体验目标：无需钱包进入 → 建成工作室 → 完成一个逻辑机关 → 留下作品纪念卡。
回访动机：新的逻辑谜题、明确可完成的建设目标、后续可分享的作品。不要依赖强制签到或付费恢复能量。
渠道：先邀请 BSC 与 X Layer 的 TapeOut 社区小规模试玩，取得社群许可后展示作品；不得冒称官方推荐。
首轮访谈建议 10–20 位真实玩家，观察其能否独立完成核心流程。
运营实验：先修首次完成率，再验证七日回访；明确有人需要新主题或工具后才测试付费意愿。
指标定义：首次作品完成率=建成首作人数/实际开始人数；七日回访=首玩后第七日回访人数/可观测首玩人数；付费转化与退款仅在未来真实支付启用后统计。
当前没有中央统计。可采用自愿访谈和人工记录，不将本机计数冒充真实用户增长。
